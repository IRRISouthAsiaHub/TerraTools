Application Guide
Required Input Format
  • Training Phenotype CSV — column 0: sample ID, column 1: numeric trait value
  • Training Genotype CSV — row index: sample ID, columns: numeric marker calls
  • Parent Genotype CSV — row index: parent ID, columns: same markers as training genotype
  • Test Genotype CSV (optional) — same marker columns, for out-of-sample GEBV prediction
Workflow
  1. Upload the three required CSV files (and an optional test genotype file) in Setup & Run.
  2. Adjust cross-validation and network hyperparameters as needed.
  3. Click Run Prediction — this trains K models for cross-validation, then a final model on the full dataset.
  4. All pairwise parent combinations are scored to identify the top-performing F1 hybrids.
  5. Review CV metrics, hybrid/parent rankings, and predictions in Results; export CSVs as needed.
  6. Inspect the hybrid ranking and GEBV distribution charts in Plots.
Model & Metrics
Model architecture: 8-layer DNN (512→512→256→128→64→32→16→8) with batch normalization, LeakyReLU, dropout, and L1/L2 regularization.
Metrics: MSE · RMSE · R² · Pearson r, evaluated via K-fold cross-validation.
Heterosis indices: Mid-Parent Heterosis (MPH) and Better-Parent Heterosis (BPH), both computed relative to the training population.
