  • Missing Data Threshold: markers with more than this fraction missing are excluded.
  • Max Recombination Fraction: marker pairs with r ≥ threshold get a 50 cM gap.
  • Monomorphic Removal: automatic — fixed-allele markers are excluded.
  • Chi-Square Filter: optional — removes segregation-distorted markers.
  • Map Scaling: proportional scales all chromosomes uniformly; uniform equalizes chromosome lengths.

Application Guide
Required Input Format
  • Excel (.xlsx): Column 1 = "Marker", Column 2 = "Chromosome"
  • Genotype columns 3+: individual sample genotype calls
  • Genotype codes are auto-converted to a / b / ab / − (missing)
  • Marker order in the input file is preserved during map construction
Workflow
  1. Upload a genotype Excel file and confirm the population type (F2 or RIL) in the Upload tab.
  2. Set thresholds and optional filters in the Parameters tab, then click Run Analysis.
  3. Review excluded markers in the QC Report tab.
  4. Browse tables and download Excel exports in the Results tab.
  5. Customize and export the linkage map figure in the Map Plot tab.
  6. Inspect marker density and adjacent-marker recombination in the Density & RF tab.
  7. Explore the interactive cytogenetic ideogram in the Cytogenetic tab.
