# TerraTools

**Website:** https://irrisouthasiahub.github.io/TerraTools/

TerraTools is a free Windows desktop app from the International Rice Research Institute (IRRI), South Asia Hub, that brings sixteen plant breeding and genomics analyses into one place. No coding and no separate R or Python installation are needed.

| Area | Tools |
|---|---|
| Data Analysis | Phenotypic Data Analysis |
| Trait Mapping | Mendelian Segregation, Linkage Mapping, QTL Mapping, QTL-Seq, Diversity Analysis, GWAS, ET-GWAS, PYBSA G-statistics, Genes Extraction, Gene Prioritization |
| Genomic Selection | Clustering & Genomic Selection, Additive Dominance, BreedSight GUI, Optimal Cross Selection, Heterosis |

## Download

- **App (Windows 10/11, 64-bit):** [TerraTools_Setup.exe](https://github.com/IRRISouthAsiaHub/TerraTools/releases/latest/download/TerraTools_Setup.exe) from the [latest release](https://github.com/IRRISouthAsiaHub/TerraTools/releases/latest). About 1.5 GB.
- **Demo input files:** one small set per tool, each runs in under five minutes (Gene Prioritization needs the internet and takes about three). Each zip has the input, the expected output and a README with the exact settings. Get them from the [website](https://irrisouthasiahub.github.io/TerraTools/#demo) or in [`downloads/`](downloads/).
- **Manual:** [`manual/TerraTools_Complete_Manual.pdf`](manual/TerraTools_Complete_Manual.pdf), and a 26-minute video tour on the website.
