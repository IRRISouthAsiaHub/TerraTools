From raw genotypes to candidate genes, in one app.

TerraTools brings sixteen plant breeding and genomics analyses together: field trials, linkage and QTL mapping, GWAS, bulked-segregant analysis, gene prioritization and genomic selection. No coding, no R or Python to install.

TerraTools for Windows

Version 1.0.0 · Windows 10 / 11, 64-bit

Download TerraTools_Setup.exe 1.5 GB

The installer already contains everything: the app, Python and a ready-to-use R environment. It is large because of that. Installed, it takes about 5 GB, so keep 6 GB of disk space free.

SHA-25660299df78a2f1a932a8e547e7602a8dde185337c501d2565aa6af20acd65faea

All releases · Check the file after downloading with certutil -hashfile TerraTools_Setup.exe SHA256

Install in three steps

  1. Run TerraTools_Setup.exe. If Windows shows a blue “protected your PC” screen, choose More info, then Run anyway.
  2. Follow the wizard and start TerraTools from the Start menu.
  3. Open a tool, load a file from the demo files and run it.
macOS? A Mac version is not published yet. Write to us if you need it.

About

TerraTools is developed by the International Rice Research Institute (IRRI), South Asia Hub, India, to put routine breeding and genomics analysis in the hands of breeders and researchers who do not want to write code.
