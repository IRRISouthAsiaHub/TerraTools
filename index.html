These plots are drawn from the files TerraTools wrote when we ran it on the demo inputs. Hover, click and change the settings to explore them. In each one a signal was planted on purpose, and the tool finds it.

437 SNPs of 300 lines. A common SNP on chromosome 3 and a rare one (MAF 0.09) on chromosome 8 control the trait. Dashed line: Bonferroni, 0.05 / 437 tests.

Sliding-window mean of the delta SNP-index (high bulk minus low bulk) on 3 chromosomes, with limits simulated by the tool. The QTL was planted on chromosome 2 at 12 Mb.

Shannon diversity of 24 samples in each of five varieties built to be increasingly diverse. TerraTools recovers the gradient and its clusters match the varieties exactly.

Get TerraTools

Download the app

TerraTools for Windows

Version 1.0.0 · Windows 10 / 11, 64-bit

Download TerraTools_Setup.exe 1.5 GB

The installer already contains everything: the app, Python and a ready-to-use R environment. It is large because of that. Installed, it takes about 5 GB, so keep 6 GB of disk space free.

SHA-25660299df78a2f1a932a8e547e7602a8dde185337c501d2565aa6af20acd65faea

All releases · Check the file after downloading with certutil -hashfile TerraTools_Setup.exe SHA256

Install in three steps

  1. Run TerraTools_Setup.exe. If Windows shows a blue “protected your PC” screen, choose More info, then Run anyway.
  2. Follow the wizard and start TerraTools from the Start menu.
  3. Open a tool, load a file from the demo files and run it.
macOS? A Mac version is not published yet. Write to us if you need it.

Try it in five minutes

Demo input files for every tool

Small files made so each tool gives a clear, legitimate result in under five minutes (Gene Prioritization needs the internet and takes about three). Each zip holds the input, what the tool produced, and a README with the exact settings.

Download all 16 demo sets 16.5 MB
1Download a zip2Open the tool, load the file3Enter the settings in the README4Compare with expected_output

Genotypes of tools 2, 3, 4, 7 and 12 to 16 come from 176 real rice lines; traits, bulks and panels are simulated with a known answer, so you can check what the tool finds. Gene Prioritization queries live public databases, so its scores can drift a little. The neural-network tools vary by about 0.03 between runs.

About
